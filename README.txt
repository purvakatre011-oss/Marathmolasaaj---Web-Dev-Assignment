MARATHMOLA SAAJ – Images Directory

This directory contains the visual assets used throughout the MARATHMOLA SAAJ website.

Folder Structure:

images/
├── products/  – Jewellery product photographs and collection images.
└── gallery/   – Brand photographs and jewellery gallery images.

Image Guidelines:

- Use high-quality JPG, PNG or WebP image formats.
- Keep image filenames simple and descriptive.
- Use lowercase letters and hyphens instead of spaces.
- Optimize image sizes for faster website loading.
- Use appropriate image descriptions (alt text) for accessibility.

All images are organized to maintain a consistent and visually appealing presentation across the website.
